# AICTE SIH Prototype 2026

A smart digital platform designed to improve government problem tracking, workflow monitoring, and transparent issue management.

## Portals

* **Public Portal:** Enables citizens to access relevant information and submit issues.
* **Administration Portal:** Supports problem management, monitoring, and administrative coordination.
* **Government Officials Portal:** Helps officials review assigned problems, update progress, and track issue resolution.

## Key Features

* Problem tracking and status monitoring
* Workflow visualization and progress tracking
* Role-based portals
* Administrative dashboards
* Transparent issue management
* Responsive user interface

## Technology Stack

* React
* TypeScript
* Vite
* CSS

## Deployment

The prototype is deployed using Vercel.

## Purpose

This project demonstrates a digital approach to improving government issue tracking, accountability, and coordination as part of the Smart India Hackathon (SIH) 2026 prototype.
